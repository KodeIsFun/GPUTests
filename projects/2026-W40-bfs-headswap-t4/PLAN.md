# 2026-W40 — BFS (Best Face Swap) head+body swap on a free T4

Owner's prompt: "next experiment is the following, we need to do the full test:
<https://huggingface.co/Alissonerdx/BFS-Best-Face-Swap>"

BFS is a LoRA collection (~150k downloads/mo, MIT) for face/head/body replacement.
The family that matches our proven stack is **Qwen-Image-2.1** (the W39/W40 base:
7B DiT, unsloth GGUF Q4_K_M / Comfy-Org int8_convrot, qwen3vl int8 TE, bf16 VAE,
fp16 cast + `--disable-comfy-compiler`). The Flux-Klein-4B and Krea-2 variants
need base models the lab has never run (FLUX.2 TE stack unmeasured on T4) —
recorded as follow-ups, not attempted here.

## How BFS-for-Qwen-2.1 works (from the repo's docs + workflow JSON)

- Two images go through the **stock** `TextEncodeQwenImage21` node: the Qwen3-VL
  text encoder sees them as `<image1>`/`<image2>` tokens AND (with `vae` wired)
  the node VAE-encodes them as reference latents spliced into conditioning.
- Contract (docs/qwen-image-2.1.md): image1 = target body/base, image2 =
  reference head — keep the order. LoRA strength 1.0.
- Official workflow (`Head Swap V1 Qwen 2.1 Workflow.json`): DiT
  `qwen_image_2.1_int8_convrot` (Comfy-Org, 7.26 GB) → LoRA **Pruna 8-step**
  (optional accelerator, strength 1) → LoRA **BFS head v1.1** (recommended,
  260 MB) → `QwenImage21Cache` → KSampler **8 steps, cfg 1.0, deis_2m, simple,
  seed 42**, refs pre-resized (lanczos) to the latent size, TE `resolution: 0`
  (refs at own size), negative prompt `""`, latent 1:1 2 MP budget (1408²).
  `deis_2m` needs RES4LYF (custom nodes); refs at own size + pre-resize are the
  template's own choice.

## Test images — consent-free by construction

All three inputs are generated by our own proven turbo pipeline (seed 42, viggle
r256 6-step), so every pixel of the run is reproducible and no real person is
involved (the model card itself demands this: no public figures / non-consent).

| input | prompt seed | size | role |
|---|---|---|---|
| `in_scene` | woman, denim jacket, rainy street, neon **"FREE GPU LAB"** sign behind her | 1408² | swap target (body) — the sign is the background-preservation canary |
| `in_head` | curly red hair, green eyes, freckles, studio portrait | 1024² | reference head |
| `in_person` | same person, full body, plain light background (the exact format the body guide trains on) | 768² | body-swap reference |

## Row matrix (all seed 42, deis_2m→fallback ladder, 8 steps, cfg 1.0)

int8 block first (one DiT resident), GGUF block after a server restart
(12.7 GB RAM box; two DiTs resident is the risk we don't take).

| row | DiT | LoRA stack | latent | why |
|---|---|---|---|---|
| R1 `head_official_1408` COLD | int8_convrot | stock-merge Pruna8 + BFS v1.1 | 1408² | the official recipe, template-faithful; cold includes load |
| R2 `head_official_1408_warm` | int8 | same graph, filename prefix changed only | 1408² | warm wall; prefix change defeats the execution cache (W40 lesson) |
| R3 `head_official_1024` | int8 | same | 1024² | speed row; bridges to the 1024² anchors |
| R4 `anchor_nobfs_1024` | int8 | Pruna8 only | 1024² | isolates BFS LoRA cost + shows what the base does with two-image conditioning |
| R7 `body_swap_1408` | int8 | stock-merge Pruna8 + **BFS body v1.0** | TE latent output (scene-sized) | guide-faithful: scene 2 MP, ref 0.59 MP, `resolution: 0` |
| R5 `head_gguf_1024` | unsloth Q4_K_M | **hook-loader** Pruna8 + BFS (ViggleTurboLora ×2) | 1024² | lab-faithful exact-update path; connects to W39/W40 anchor numbers |
| R6 `head_gguf_merge_1024` | unsloth Q4_K_M | stock-merge Pruna8 + BFS | 1024² | author-faithful path on quantized weights → merge-vs-hook delta |

Ladders (each recorded, never silent): sampler `deis_2m` → `res_2m` → `deis`
→ `res_multistep`; autogrow images API format nested-dict → flattened
`images.image_N`; int8 merge error → hook-loader fallback; GGUF cache-node
error → drop `QwenImage21Cache`. Every row's graph JSON is asserted distinct
(W40 cache-hit lesson). OOM/RAM watch per row via `/system_stats` + psutil.

## Quality evaluation (numbers into timings.json, best-effort per block)

1. **Identity (if insightface installs; CPU ArcFace, hard timeout):** cosine
   sim of output face vs reference-head face (up) and vs scene-person face
   (down) — the anchor row calibrates both.
2. **Background drift:** grayscale SSIM output-vs-scene, whole frame and the
   bottom 45% (below the head) — the sign region must survive.
3. **Canary:** "FREE GPU LAB" legibility in every output, eyeballed from the
   committed PNGs and stated in the README.
4. sha256 of every PNG (W40: same-seed renders are deterministic across VMs).
